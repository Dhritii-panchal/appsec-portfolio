# Application Security Portfolio

This repository contains hands-on application security practice
performed using vulnerable labs and platforms.

## Skills Demonstrated
- Web Application Security Testing
- OWASP Top 10
- Broken Access Control (IDOR, Privilege Escalation)
- API Security (BOLA, Mass Assignment)
- Manual testing using Burp Suite

## Tools Used
- Burp Suite Community Edition
- PortSwigger Web Security Academy
- TryHackMe

## Disclaimer
All testing was performed on intentionally vulnerable labs
for educational purposes only.
